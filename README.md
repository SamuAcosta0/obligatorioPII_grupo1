# **Obligatorio Programación II - 2026**

## Descripción del proyecto

Doors OS- Process Manager es un sistema de administración de procesos desarrollado en Java para el Obligatorio de Programación II.

El sistema permite cargar usuarios y procesos desde archivos CSV, calcular prioridades, ejecutar procesos según dichas prioridades, registrar eventos en archivos de log y consultar el estado de los procesos almacenados en memoria.

## Funcionalidades 

- Cargar usuarios desde un archivo CSV.
- Cargar procesos desde un archivo CSV.
- Calcular prioridades de los procesos.
- Ejecutar procesos según sus prioridades.
- Registrar eventos en archivos de log.
- Consultar el estado de los procesos almacenados en memoria.

## Estructuras utilizadas 

- Hash para usuarios.
- Queue para procesos nuevos.
- Heap para procesos pendientes.
- Stack para procesos finalizados.
- Linked List para eventos e instrucciones.
